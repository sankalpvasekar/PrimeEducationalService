# Project Requirements

This project requires the following environment to run:

- **Node.js**: Version 20.x (LTS)
- **npm**: Version 9.x or higher
- **PostgreSQL**: A running instance for the database
- **Environment Variables**:
  - `DATABASE_URL`
  - `CLOUDINARY_CLOUD_NAME`
  - `CLOUDINARY_API_KEY`
  - `CLOUDINARY_API_SECRET`
  - `ADMIN_EMAIL`
  - `ADMIN_PASSWORD`
  - `RAZORPAY_KEY_ID`
  - `RAZORPAY_KEY_SECRET`

Ensure these are set in a `.env.local` file in the root directory.
